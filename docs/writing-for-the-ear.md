# Writing for the ear

Narration passes once through a listener's attention. They cannot scan backward, inspect
the punctuation, or reread a parenthetical. Write for that single forward pass.

Apply this guide to the prose script as a whole, before it is segmented into `say` values.
A future beat is a useful visual unit, but it is not an excuse to judge each sentence in
isolation. The complete narration must pass this gate before any storyboard is shown.

## Vary the rhythm

Short sentences are useful. A script made only of short sentences is not. It sounds flat,
staccato, and assembled one card at a time.

Mix brief lines with medium sentences and occasional longer sentences. Let short lines
land a point. Use longer lines when cause, contrast, or consequence belongs in the same
thought. Connectives such as *because*, *but*, *so*, *while*, *which*, and *yet* should do
real work rather than decorate two unrelated ideas.

"One idea per beat" still applies. It keeps the visual plan legible; it does not require
uniform sentence length. A longer sentence must remain easy to follow when heard once.
Judge the distribution across the whole script. Issue #13 owns the numeric calibration
for that distribution.

## Banned patterns

The quoted phrases below are lint triggers, not narration examples to imitate. Match them
case-insensitively and allow ordinary punctuation or whitespace between their words.

| Pattern | Flag when | Common signals |
| --- | --- | --- |
| Binary contrast | A sentence negates one label only to replace it with another. | `it's not X, it's Y`; `this isn't X; it's Y`; `not X, but Y` |
| Throat-clearing opener | A sentence delays the point with a conversational preface. | `here's the thing`; `let's be honest`; `the truth is`; `look` |
| Faux-insight setup | The writer claims privileged understanding before saying anything concrete. | `what most people get wrong`; `what nobody tells you`; `the secret is`; `you might be surprised` |
| Colon reveal | A setup fragment uses a colon to unveil a slogan or verdict. Flag any colon in a `say` value for review. | `the result: X`; `one thing changed everything: X` |
| Importance puffery | A sentence announces importance instead of demonstrating it. | `this is important`; `this matters more than ever`; `this cannot be overstated`; `the stakes are high` |
| Weasel attribution | A claim is assigned to an unnamed authority or group. | `experts say`; `research shows`; `studies suggest`; `many believe`; `it is widely known` |
| Negative listing | Two or more consecutive clauses or sentences are built from what is absent. | `no X. no Y. no Z.`; repeated openings with `no`, `not`, or `without` |
| Dramatic fragmentation | A thought is split into a row of fragments for manufactured intensity. | `X. And Y. And Z.`; two or more consecutive fragments beginning with `and` or `but` |
| Rhetorical setup | The narrator asks a question only to answer it immediately. | `why? because`; `the result?`; `what happens next?` |
| Fake-profound kicker | A sentence asks the listener to admire the preceding claim. | `let that sink in`; `read that again`; `think about that`; `and that changes everything` |
| Summary-recap ending | The ending labels or repeats a summary instead of leaving the listener with a final idea. | `in conclusion`; `to sum up`; `the takeaway is`; `so there you have it` |

Do not evade a trigger with punctuation, contractions, or a close paraphrase. Remove the
setup and state the concrete point. A mechanical lint can flag the signals; the writer is
still responsible for catching equivalent phrasing.

## Write what the voice should say

- Write numbers as they should be spoken. If the voice should say "twenty twenty-six,"
  write those words instead of `2026`. Spell out decimals, ranges, currency, dates, and
  symbols according to the intended pronunciation.
- Remove parentheticals. A listener cannot see which words were tucked into parentheses.
  Make the thought a sentence, connect it to the sentence, or cut it.
- Do not use page-position references such as `as mentioned above`, `below`, or `earlier`.
  Restate the needed idea or use a transition that makes sense in time.
- Expand an acronym on first use and make its pronunciation unambiguous. For example, say
  `application programming interface, or A P I` before using `A P I` alone.
- Do not read visual layout aloud. Bullets, headings, slash-separated choices, and other
  fragment lists belong in `show`; narration uses complete spoken sentences.
- Do not add `<break>` tags. Shape the sentence and whitespace so the continuous read has
  the intended pace.

## Dialogue without filler

Dialogue prose uses one complete thought per paragraph and prefixes it with a speaker tag,
such as `[host]` or `[guest]`. The tag selects a voice and is not spoken. Use exactly two
speaker names throughout the script.

A genuine question hands uncertainty to the other speaker and ends the turn. Do not let a
speaker ask a question and answer it in the same paragraph; that is a monologue wearing a
dialogue costume. Clarifying questions may test an assumption, request an example, or name
the point where a listener could lose the thread. Skeptical questions and disagreement are
welcome only when the source material supports them. Never invent a position to make the
exchange livelier.

Cut conversational padding that does not change the listener's understanding:

- reflexive affirmations such as `Right`, `Exactly`, and `Absolutely`;
- praise for the prompt, including `Good question` and `That is a great point`;
- handoffs such as `I was just going to say`;
- rhetorical questions that the same speaker immediately answers.

Each response should advance, qualify, or challenge the previous turn. If removing a line
leaves the meaning unchanged, remove the line.

## Final read-through

Before storyboard, read the joined narration aloud at a natural pace and confirm:

- sentence lengths vary across the script while longer thoughts remain clear in one pass;
- transitions carry meaning when the visuals are hidden;
- no banned word or banned pattern remains;
- every number, symbol, and acronym is written the way it should sound;
- no parenthetical, page reference, or visual-only fragment asks the listener to read;
- consecutive beats sound like one continuous performance rather than isolated clips.
- dialogue questions create real handoffs, both speakers contribute substance, and neither
  voice falls into affirmation or filler banter.

If any check fails, revise the prose script and run the gate again. Re-segment only after
it passes; do not move the problem downstream to storyboarding, voice generation, or
editing.
